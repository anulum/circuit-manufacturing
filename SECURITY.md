# Reporting a concern

The repository has no released executable runtime or hosted service. No released version is represented as supported or independently assessed.

Report a suspected vulnerability privately to Miroslav Šotek at protoscience@anulum.li. Include the affected source revision, environment and a bounded description of the observable behaviour. Do not post credentials, customer designs, confidential foundry mask data, wafer-sort lot feeds, unit serial genealogies, cryptographic provisioning logs or sensitive files in a public report.

The maintainer coordinates assessment and any disclosure. No guaranteed response or remediation time is claimed. A source or signature check does not establish runtime isolation, hardware-security-module custody, counterfeit immunity, chemical safety or permission to release a tapeout package, disposition a lot or ship hardware.
